# 模型来源与隐私授权

## 两件事，两个页面

- **模型**决定使用谁处理请求：选择“使用 DSH 中的模型”或“自定义模型”，只保存一个明确选择。
- **隐私**决定请求可以包含什么：目标内容、项目背景、收集原文分别授权。

两个菜单打开不同页面，不是同一合并页的两个别名。本机、远端和 ChatGPT 等品牌不再作为平级配置类型；本机服务只是自定义 API 地址的一种情况。

## 使用 DSH 中的模型

从按提供方分组的列表选择一个模型，再保存。Zodo 不读取、继承或修改当前聊天所选模型。订阅或 OAuth 模型只要由 DSH 的真实 llm 服务支持，就通过该服务执行，而不是复制端点/密钥后假装成通用 API。

调用链：Core 构造获准上下文 → 经鉴权的本机 Host 通道 → DSH 所选 provider/model → 模型输出回到 Core 生成候选。不会添加 DSH 聊天历史、工具或会话身份；凭据仍由 DSH 管理，不复制到 Core 模型配置或浏览器。

Host 不可用、模型从目录消失、认证过期或提供商限额不足时明确失败，不自动换成别的模型或自定义连接。目录可选和预检通过不代表已完成真实推理测试，订阅自身的配额与上游限制依然生效。

## 自定义模型

填写 OpenAI 兼容 API 地址和模型 ID。例如本机 Ollama 可使用回环地址；远端服务使用其提供的 API 地址。需要鉴权时，在折叠的认证设置中填写 Core 环境变量名；不需要鉴权的服务可留空。此处不是 API Key 输入框，不会读取、显示或保存密钥值。

Core 直接调用选定端点。密钥只从 Core 启动环境获取；环境变量修改后需按运维流程重启 Core。模型失败不跨连接回退。

## 隐私：控制 Zodo 内置 AI 的请求内容

默认全部关闭，保存时才生效；同时适用于 Zodo 目标拆解与收集澄清采用的 DSH 和自定义模型。模型配置不改变隐私，隐私保存不改变模型。

这三个开关不是 DSH 全局资料外发防火墙，不控制聊天中主动请求的 native tools、文件读取、导出或手动粘贴。那些通道仍由 DSH 权限、内容等级和各自确认流程控制。不要把“内置 AI 未授权”理解为“当前 DSH 聊天永远读不到这些资料”。

| 授权 | 实际效果 |
|---|---|
| 目标内容 | 允许目标标题、成功标准、截止日期、计划视界进入拆解请求；关闭则不派发目标拆解模型调用 |
| 项目背景 | 允许关联项目名称和范围；关闭时裁剪项目上下文，仍可在已授权目标内容的前提下拆解目标 |
| 收集原文 | 允许主动收集文本进入澄清请求；关闭则不派发收集澄清模型调用 |

笔记正文、附件和聊天历史不会自动附加。授权开关不是脱敏器，请勿把禁止外发内容复制到获准字段中。内容自身的数据等级不因模型或授权切换改写。

明确标记为 DeviceOnly 的内容不能交给无法验证最终目的地的 DSH 路由；本机处理必须是受验证的自定义回环端点。一个本机代理 URL 或“本地”显示名不证明下游仍在设备内。任何本机地址都不自动获得更多内容权限。

## 技术与安全边界

模型配置为严格 v2 tagged source，无本地/云端双槽、角色路由、提供方通配授权或旧结构迁移。策略为严格 model_access 与诊断开关。未知字段和旧结构拒绝，不做隐式转换。

Host 通道凭证仅保存在内存；每次派发受 Core 实例、模型选择、策略修订、运行与上下文范围约束。不得将回调凭证、provider 登录 token 或模型原文错误回显到公开 API、日志和发布包。

私密 Host 历史拦截、Agent 无审批/提交权限、内容等级、schema/版本校验、单 writer 和备份完整性边界保留。应用鉴权不是同 UID 的操作系统强隔离。已经发出的内容不能追溯收回；取消和权限撤销阻止尚未派发或仍可中止的工作。

## 安装与验证

更新应让 Core 与 Host 插件一起加载当前版本。先备份，确认没有必须继续的运行，再替换 Core；开发期过期设置应明确重置，而不是在产品中添加兼容逻辑。不要删除业务实体。Host 重启后重新建立内存调用通道，不复用过期凭证。

测试使用合成提供商、临时 Core 与实际 Host 模块，不调用真实付费模型。Mock 的订阅 provider 验证“不需复制端点或密钥也能走 DSH 调用链”，不代表任意真实账号的认证或配额已验证。安装验证不能用另起一个 fixture 冒充当前 GUI 已更新。
