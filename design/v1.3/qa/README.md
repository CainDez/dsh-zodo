# 资料验证范围

本目录记录版本1.3设计文档及交接包的验证。没有执行产品开发、Harness插件集成、Rust产品测试、真实模型评测或目标平台运行测试。

Word正文由本包的Markdown规格生成。使用WPS COM导出PDF，再以PDFium渲染每页原始PNG并逐页视觉检查；自动检查页内文字边界、空页、图片数量与文件哈希。渲染PDF和PNG保留在设计工作区内部，不作为产品截图打包。软件方案、开发计划和视觉参考册的最终页数及每页审阅结果见 [document-review.json](document-review.json)。

内容审计已统一Rust内核独立性、Harness/Flutter顺序、A0–A7阶段、两种批准、会话日志与模型切换隐私、高权限宿主信任边界、生命周期和回放语义。A0只证明插件和最小测试进程桥接；真实业务和模型/MCP在A2/A3验收。25个宿主测试用例当前均未执行。

相对链接、JSON、30行逐屏覆盖表、25行宿主测试表、七张旧视觉参考的SHA256及旧1.2资料完整性由设计检查验证；见 [design-consistency.json](design-consistency.json)。七张旧图没有改绘为Harness新界面，界面实现状态仍为未实现。

原始资料包可运行 `python tools/verify_bundle.py` 复核每个文件、相对链接和SHA256。这是未修改的设计快照校验，不是新项目产品测试；实际开发后保留原始快照，另外积累实现和测试证据。
